# Portfolio image assets

The three current portfolio projects use `design-01.jpg.jpeg` (Sunday Studio), `design-02.jpg.jpeg` (Forma Objects), and `design-03.jpg.jpeg` (Serein Living), in the site's existing display order. Their image paths are stored in the project's `image_url` fields. New project images may be stored here and referenced by a local `/static/images/portfolio/...` path.
